# 🔥💧 Fogo & Água

Jogo cooperativo para **2 jogadores no mesmo teclado**, feito em HTML, CSS, JavaScript e jQuery como projeto acadêmico do curso de Sistemas de Informação (UGB).

**▶️ [Jogar agora](https://brunett06.github.io/fogo-e-agua/)**


## Como jogar
| Personagem | Controles |
|---|---|
| 🔥 Fogo | `W` `A` `S` `D` |
| 💧 Água | Setas do teclado |

1. Cada personagem precisa coletar **5 cristais** da sua cor.
2. Depois disso a **porta** aparece, e os dois precisam chegar até ela.
3. Tudo isso em **60 segundos**. Se o tempo acabar, é game over.

## Funcionalidades
- Movimentação simultânea dos dois jogadores (leitura de várias teclas ao mesmo tempo)
- Detecção de colisão entre personagens, cristais e porta
- Placar, cronômetro e barra de tempo
- Cristais que reaparecem em posições aleatórias
- Efeitos sonoros de coleta, vitória e game over
- Telas de início, vitória e game over

## Tecnologias
HTML5 · CSS3 · JavaScript · jQuery
